# Markmap 层级图

## 模板

````md
```markmap size=900x560
# 平台
## 接入层
- Web
- API
## 服务层
### 用户服务
### 订单服务
## 数据层
- PostgreSQL
- Redis
```
````

## 编写方法

1. 根标题回答“这棵树是什么”。
2. 二级标题表示主要分类。
3. 三级标题或列表表示具体项。
4. 每个节点尽量控制在 2-12 个字或几个英文单词。
5. 超过五层或单层几十个节点时拆成多张图。

## 安全与限制

- 不写 `<img>`、`<script>`、`<span>` 等原始 HTML。
- 普通 Markdown 链接可以表达参考地址，但离线打开不代表链接目标离线可用。
- Markmap 适合树，不适合多对多依赖；后者改用 Mermaid flowchart，复杂时拆图或改用表格。
