# Mermaid

Mermaid 适合在 Markdown 中维护流程、交互、计划、数据关系和状态变化。它在浏览器打开页面后渲染，因此构建成功后仍应做浏览器检查。

## 选型

| 需求 | 文档 |
| --- | --- |
| 步骤、分支、数据流 | `flowchart.md` |
| 参与者之间的消息顺序 | `sequence.md` |
| 时间计划和依赖任务 | `gantt.md` |
| 实体、字段和基数关系 | `er.md` |
| 少量类别的占比 | `pie.md` |
| 生命周期和状态迁移 | `state.md` |

## 通用规则

- 默认使用 `mermaidSecurity: strict`。
- 节点标签保持简短；长解释放在图后正文。
- 一张图只表达一个主要问题，节点过多时拆分。
- 使用方向体现阅读顺序：过程常用 `LR`，层级或审批常用 `TD/TB`。
- 如需固定视口，fence 使用 `size=宽x高`，不添加其他参数。

````md
```mermaid size=760x420
flowchart LR
  A[输入] --> B[处理]
  B --> C[输出]
```
````

Mermaid 支持页面工具栏中的 1%-1000% 缩放和源码切换，但不要用缩放代替合理拆图。
