# 代码块与表格

## 代码块

始终标注语言：

````md
```json
{
  "theme": "dark"
}
```
````

支持：

- highlight.js 语法高亮。
- 语言标签和图标化复制按钮，受 `codeTools` 控制。
- 始终提供“收起/展开”按钮；默认展开。
- 复制和收起/展开按钮使用图标，并通过悬停提示及 `aria-label` 说明用途。
- `codeCollapse: true` 或 `--code-collapse` 可让代码较多的文档初始收起，打开后仍可手动展开。
- 打印时自动展开，避免文档遗漏。

不使用 `code-group` 或 tab，因为隐藏代码可能无法完整打印。

## 表格

表格适合字段、对比、清单和精确值：

```md
| 方案 | 延迟 | 成本 | 备注 |
| --- | ---: | ---: | --- |
| A | 120 ms | 100 | 稳定 |
| B | 90 ms | 135 | 成本较高 |
```

数字列右对齐。列数过多时拆表，不使用 HTML 合并单元格。
