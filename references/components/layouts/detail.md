# 受限折叠块

折叠块把次级细节、附录或可选说明收进可展开区域，正文保持简洁，读者按需展开。

## 模板

两种写法等价，标题写在与标记同一行的参数位置：

```md
:::detail 参数说明

折叠体内可以放普通 **Markdown**、代码块和所有图表。

:::
```

```md
<detail>参数说明

折叠体内容。

</detail>
```

## 规则

- 标题取首行参数，支持行内 Markdown（如 `` `代码` ``、`**粗体**`）；缺省时使用默认标题“详情”。
- 折叠块默认收起；点击标题展开/收起，打印时内容强制展开。
- `:::detail` 以单独一行的 `:::` 闭合；`<detail>` 以单独一行的 `</detail>` 闭合。
- 闭合标记必须独占一行；代码 fence 内的 `:::`、`</detail>` 行保持为代码，不参与解析。
- 不接受 open、class、style 或其他属性；未闭合或变体写法按普通 Markdown 保留，不会自动猜测修复。
- 同语法不嵌套（内层闭合行会提前闭合外层）；两种语法可以互相嵌套。
- 目录或标题锚点指向折叠块内的标题时，会先展开折叠块再跳转。
