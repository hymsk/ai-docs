## 一、五个方向独立收敛的共同结论（本系列的最高价值）

各方向调研彼此独立进行，但结论高度收敛。以下八条是**跨方向复现**的发现，可信度高于任何单篇报告：

### 1. 先澄清后生成，是所有方向的第一杠杆
- 需求：访谈式澄清使 ER 图工时降低 ~95%，隐含需求覆盖率 +33%（02 §2.1）
- 架构：代码证据不足时正确行为是列 open questions 追问，而非编造（05 P1）
- 交互：Escalation Pathway——好的 Agent 不猜，而是升级求助，健康求助率 5–15%（01 §4）
- 共同形态：分组提问、一次一题、HITL 中断确认。

### 2. 任务分解 > 一步到位，但"多 Agent"≠"更好"
- 正面：ReqInOne 三子任务分解超越初级工程师（02 §2.2）；Goal2Story 结构化编队胜过单个 Super-Agent
- 反面（跨领域双重复现）：IDRAAK 中 few-shot 单次调用击败 8-Agent 流水线（03 §1.4）；《Illusion of Agentic Complexity》证明多 Agent RAG 生成 README 无显著增益（04 §7.2）
- **合成结论**：按领域结构做"专职子任务"分解有效；按角色数量堆 Agent 无效。一切复杂度引入必须由评测数据驱动。

### 3. 确定性打底 + LLM 增强，是最可靠的混合范式
- AST/静态分析提取事实，LLM 只负责"把事实转译成人话"（04 §3.1；05 P3）
- 调用关系必须由静态分析确定性提取，不能指望模型自己看出来（04 §7.1 RepoAgent 实证）
- 规则工具管结构下限，LLM 管语义上限："Dual-gate 双闸门"（03 §4.1）＝"确定性检查 + LLM-as-Judge 三层指标栈"（04 §7.3）。

### 4. 强制溯源是反幻觉的公共解
四个方向各自独立发明了同一机制：
| 方向 | 形态 | 指标 |
| --- | --- | --- |
| 02 需求 | Trace-to-Source + Reason 字段 | 幻觉需求显著抑制 |
| 04 代码 | `file:line` 强制引用锚点 | Existence Ratio 95.74% vs 基线 61.10% |
| 05 架构 | 证据三级标签（fact/inference/open question）| Claims 注册表自动置 stale |
| 01 交互 | 证据式写作 + `[待验证]` 显式标注 | 用户可跳转验证，信任可校准 |

### 5. 生成只是开始：增量更新 + CI 门禁才是长期价值
- 触发：webhook 优于 cron（05 §9.1）；OpenWiki 定时跑 git diff 只更新受影响页并以 PR 交付（01 §6.3）
- 成本：内容哈希缓存节省 60–90% token（04 §3.4 / 05 §5 / RepoDoc -77%）
- 门禁：AST 符号锚点漂移检测 + Freshness Score，让"文档过期"成为和测试失败同级的问题（05 §9）
- 人写保护：白名单外段落 Agent 不得触碰（05 §9.4）↔ 对抗 Authorship Drift 的心理学依据（01 §11.3）。

### 6. 文档的一等读者已经包括 Agent（双受众架构）
- GitBook 数据：Agent 占文档阅读量 51.8%，超过人类（01 §14.1）
- 双资源模型：人类稀缺注意力，Agent 稀缺 token（01 §14.2）
- 机读三件套：`llms.txt`（索引，注意 97% 零请求争议）+ `.md` 直链 + MCP 查询接口（01 §14.3 / 04 §8.1）
- 关键反直觉发现：LLM 生成的泛化 AGENTS.md 反而损害 Agent 表现，机读文件要做减法（04 §8.1）。

### 7. 人机协同不是妥协而是必要
- HITL 中断点、澄清日志、局部再生成构成可持续迭代闭环（02 §2.6）
- "AI 提案，人类决策"：组织政治、隐性历史决策不在代码里（05 P10）
- 产品化形态：自主度旋钮 L0–L3 分级放权（01 §4 模式二）
- 可中断性是长任务刚需：追加/修正/撤回三种中断语义（01 §13 InterruptBench）。

### 8. 评估驱动迭代，没有评测就没有架构决策权
跨方向通用的三条硬指标：
| 维度 | 各方向测量对象 |
| --- | --- |
| **覆盖率** | 该写的都写了吗：符号覆盖（04）、章节完整度（05）、隐含需求覆盖 IRE（02/03） |
| **真实性** | 引用的存在吗：Existence Ratio（04/05）、FHR（02/03）、幻觉率回查 |
| **有用性** | 读者能用吗：新人上手时长 A/B（04）、Likert 五维（02）、QA 式评测（拿文档当知识库答题判分） |

## 三、格式约定（本系列统一规范）

- **文件命名**：`NN-方向名[-进阶篇].md`，两位序号保证排序稳定；
- **页眉块**：标题行 `调研报告 NN · 方向名：副题`，引用块包含 系列/方向/日期/信息来源/姊妹篇 导航；
- **章节编号**：统一阿拉伯数字 `## N.`，目录锚点与之对应；
- **互鉴章**：每篇倒数第二章为"与系列其他报告的互鉴"，以表格形式给出概念 ↔ 姊妹篇对应实践 ↔ 交叉启示，链接使用相对路径；
- **参考资料**：每篇最后一章，按 论文/开源项目/工程实践 分类。
